**보안 관련 수정 내용 (공식 릴리즈 노트 기준):**

- SOCKS 프록시 GSSAPI/SSPI zero-length 토큰 거부 — 인증 우회 방지
- 파일명 기반 쉘 인젝션 위험 방지 수정
- 파일 디스크립터 초기화(-1) 수정 — 조기 실패 시 fd 0 close 방지
- 메모리 안전성 개선 (버퍼 오버플로우, use-after-free 다수 수정)

**주요 변경사항 (Breaking Changes 포함):**
- RTMP 프로토콜 지원 완전 제거
- SMB 지원 기본 비활성화 (opt-in으로 변경)
- NTLM 빌드 기본 비활성화
- c-ares 1.16.0 미만 버전 지원 중단
- CMake 3.17 이하 지원 중단

**권장 조치**:
- 자사 libcurl 사용 버전 확인 후 8.20.0 이상으로 업그레이드 검토
- current_version 등록 후 영향도 재판단 필요
