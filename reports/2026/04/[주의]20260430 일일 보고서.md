## 🟡 주의 사항

### [MODERATE] @anthropic-ai/sdk (TypeScript): Insecure Default File Permissions in Local Filesystem Memory Tool

- **GHSA ID**: GHSA-p7fg-763f-g4gf
- **CVSS 점수**: MODERATE (CVSS 수치 미공개)
- **영향 범위**: @anthropic-ai/sdk >= 0.79.0, < 0.91.1 (NPM)
- **자사 영향**: 확인 필요 — TypeScript/Node.js 환경에서 `BetaLocalFilesystemMemoryTool` 사용 시 적용
- **공식 링크**: https://github.com/anthropics/anthropic-sdk-typescript/security/advisories/GHSA-p7fg-763f-g4gf
- **발표일**: 2026-04-29

**취약점 설명**: `BetaLocalFilesystemMemoryTool`이 Node.js 기본 모드(`0o666` 파일, `0o777` 디렉토리)로 메모리 파일/디렉토리를 생성하여, 표준 umask 환경에서 world-readable 상태가 됩니다. umask가 허용적인 환경(Docker 기본 이미지 등)에서는 world-writable이 되어 로컬 공격자가 에이전트 상태를 읽거나 메모리 파일을 수정하여 모델 동작에 영향을 줄 수 있습니다.

**권장 조치**:
  - TypeScript 프로젝트에서 `@anthropic-ai/sdk` 사용 여부 확인
  - 사용 중이라면 `0.91.1` 이상으로 업그레이드
  - `BetaLocalFilesystemMemoryTool` 사용 여부 확인 (미사용 시 영향 없음)
  - Docker/컨테이너 환경에서 운영 중인 경우 우선 조치 권장

```bash
# 업그레이드 명령
npm update @anthropic-ai/sdk
# 또는
npm install @anthropic-ai/sdk@latest
```
